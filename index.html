How to play

    
Write Python-like code that keeps the world sustainable for the full run.
       Every action advances time and has pros and cons — needs vs. emissions, output vs. pollution, comfort vs. health.


    
Three Game Modes

    
    
      
  • Easy Mode: Loads the tested reference solution code. Perfect for testing, observing resource dynamics, and seeing a Grade A solution in motion.
    • 
      
  • Medium Mode: Loads half right and half wrong code. It has real bugs, missing guards, and trade-off imbalances. Your challenge is to debug and tune it to reach Grade A!
    • 
      
  • Hard Mode: No starter code! You only get the function signature and the Suggestions & API Guide with recommended methods and strategic hints. Architect the full system from scratch.
    •

def name(a, b=2):        # functions with default args

Stage API

    

    
Rules

    
    
      
  • Each action = 1 tick of time (long computations also burn ~1 tick per 40 steps).
    • 
      
  • An action you cannot afford raises an error and stops your program. Guard actions with probes!
    • 
      
  • When your program ends, the world keeps running to the tick limit without you.
    • 
      
  • Score ≥ 60 clears the stage; aim for 85+ (grade A). Clear a stage to unlock the next.
